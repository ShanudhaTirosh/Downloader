Everything You Need
In One Tool

From HTTP downloads to torrents, social media ripping to media conversion — ShanuFx handles it all without breaking a sweat.

⚡

Universal HTTP Downloader

IDM-style multi-segment HTTP/HTTPS downloading with resume support, speed throttling, and parallel chunk management.

requests · urllib3

Social Media Engine

Powered by yt-dlp — download from YouTube, Twitter, Instagram, TikTok and 1000+ more sites in any available quality.

yt-dlp · 1000+ sites

Torrent Engine

Full BitTorrent protocol via libtorrent. Magnet links, .torrent files, DHT, PEX, and bandwidth control built-in.

libtorrent · DHT

Media Converter

Convert between video and audio formats on the fly. Embed metadata, album art, and tags with mutagen integration.

mutagen · Pillow

Queue Management

Drag-and-drop priority queue, scheduled downloads, auto-start on system boot, and per-category organization.

For Developers

Build Your Own One

Follow these steps to set up the development environment and build your own version of ShanuFx Downloader.

01
Clone the Repository
Get the latest source code from GitHub onto your machine.
git clone https://github.com/ShanudhaTirosh/Downloader.git
cd Downloader
02
Create Virtual Environment
Isolate dependencies from your system Python installation.
python -m venv venv
.\venv\Scripts\activate   # PowerShell / CMD
03
Install Dependencies
All required packages are pinned in requirements.txt for reproducibility.
pip install -r requirements.txt
04
Launch ShanuFx Downloader
Run the main entry point and start downloading at full speed.
python main.py

Codebase

Clean Project Layout

Every file has a single responsibility. The modular architecture makes it easy to extend, test, and maintain.

ShanuFx-Downloader/ 
ShanuFx-Downloader/
├── main.py             ← Application entry point, Qt app init
├── config.py           ← Global settings, constants, paths
├── theme.py            ← QSS stylesheets, glassmorphism theme
├── requirements.txt    ← Pinned dependency manifest
├── README.md           ← Documentation & quickstart guide
│
├── core/               ← Engine & business logic (no UI here)
│   ├── downloader.py   ← HTTP multi-segment download engine
│   ├── yt_handler.py   ← yt-dlp wrapper, site extraction
│   ├── torrent.py      ← libtorrent session management
│   ├── converter.py    ← Media format conversion logic
│   ├── queue.py        ← Download queue & scheduler
│   ├── database.py     ← SQLite ORM, history persistence
│   └── diagnostics.py  ← psutil stats, network test, logger
│
├── ui/                 ← PyQt6 widget definitions
│   ├── main_window.py  ← Root window, tab container
│   ├── download_tab.py ← URL input + active downloads list
│   ├── queue_tab.py    ← Queue management UI
│   ├── history_tab.py  ← Completed downloads viewer
│   ├── settings_dlg.py ← Preferences dialog
│   └── widgets.py      ← Reusable custom Qt widgets
│
└── assets/             ← Static resources
    ├── icons/          ← SVG icon set
    ├── fonts/          ← Embedded font files
    └── splash.png      ← Startup splash screen

How to Contribute

We welcome all contributions — bug fixes, new site support, UI improvements, and feature additions. Here's the workflow:

STEP 01
🍴
Fork Repo
Fork ShanudhaTirosh/ShanuFx-Downloader to your GitHub account
→
STEP 02
🌿
Create Branch
Branch off main with a descriptive name like feat/aria-support
→
STEP 03
💻
Write Code
Follow the modular pattern. Keep UI and logic separated in ui/ vs core/
→
STEP 04
🧪
Test Locally
Run the app end-to-end and verify your change doesn't break existing features
→
STEP 05
📬
Open PR
Submit a pull request with a clear description of what changed and why
Star on GitHub 🐛 Report an Issue
